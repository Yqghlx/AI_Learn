## 《智能硬件接入 WorkBuddy 白皮书》改成暗色版
- 源：https://www.workbuddy.link/p/JVM0gKdRyl8k9EgElw5TxA 。发布页本体是 SPA 壳，真实静态资源在 window.__PUBLISH_BOOTSTRAP__.artifact.url + 文件名里，本次为 https://workbuddy-space-static.codebuddy.work/page/<nodeId>/<version>/WorkBuddy_v4__.html（curl 直接可得，无需登录）。以后要抓 workbuddy.link 页面内容就这么取。
- 产出：WorkBuddy-智能硬件白皮书-暗色版.html（只 HTML，未做 PDF）。
- 做法沿用 OPC 暗色版的三层叠加（全部包在 @media screen { html.dark ... } 内，打印时自动回退浅色）：
  1. 变量层：html.dark{--blue:#5b8cff ... } 重定义整条调色板（html.dark 权重高于 :root）。

  3. 内联层：132 处 style="..." 里有 20 多种颜色组合，用 html.dark [style*="background:#fff"]{background:#1b1f26 !important} 这类属性选择器解决。
- 收尾反查：脚本遍历所有内联 style 的 color/background/border 声明，检查是否都命中映射或属于白名单（白字、品牌底），确认无遗漏。这个反查步骤值得复用。
- 切换沿用 OPC：head 顶部 bootstrap 防闪烁 + #theme-toggle 按钮 + 快捷键 D + localStorage（key 用 hw-wp-theme，默认暗色）。
