# DESIGN.md — 深空科技 · Coding Agent 实战指南

## 风格依据
用户选定预览卡 A · 深空科技（未命中 academic / consulting / redgold 任一预设分支，走通用设计原则 + 用户显式选定色板）。气质词：深空 · 高对比 · 代码质感 · IDE 夜色 · 克制理性。面向一线工程师的内训场景，深色底在投影环境下对比强、长时间观看不刺眼，且天然贴近开发者日常 IDE 观感。

## 1. 画布与母版（硬值）

- 画布：**1280 × 720 px**（16:9）
- 页面 padding：上 20 / 下 20 / 左 64 / 右 64
- **A · 标题块**：y 0–120px。主标题 36px bold，左侧对齐 x=64；标题下 4px 处一条 56×3 青绿短条（全篇固定）；标题右上角不放任何装饰图。
- **B · 内容区**：y 120–660px，可用高 540px。所有正文 / 图表 / 卡片 / 配图在此区内。
- **C · 页脚条**：y 660–720px。左侧 `Coding Agent 实战指南 · 研发效能内训`（14px，rgba(232,237,245,0.45)）；右侧页码 `NN / 21`（14px，JetBrains Mono，青绿）。x 起点 64，右端 1216。
- 封面 / 章节扉页 / 结束页：省略 C 区页码条，采用自定义版式。

## 2. 色彩池（4 hex，全篇不得超出）

| 角色 | HEX | 用途 | 面积上限 |
| :-- | :-- | :-- | :-- |
| 主色 · 深空底 | `#0F1B2D` | 页面背景、大色块、章节底、卡片深底 | ≤ 60% |
| 强调色 · 青绿 | `#35D0BA` | 巨型数字、焦点数据、标题短条、页码、关键高亮 | ≤ 10%（Hero 页 15–20%） |
| 辅色 · 电光蓝 | `#4C8DFF` | 图表第二系列、次级标签、流程箭头、渐变尾端 | ≤ 30% |
| 文本主色 · 冷白 | `#E8EDF5` | 所有正文与标题文字 | 剩余 |

中性灰由文本主色降透明得到：`rgba(232,237,245,0.55)`（次级文字）、`rgba(232,237,245,0.45)`（页脚）。

**卡片表面**：`background: rgba(232,237,245,0.06)` + `border: 1px solid rgba(232,237,245,0.12)` + `borderRadius: 10`。
**深块表面**：`background: rgba(15,27,45,0.72)`。

### 2.1 面积分配基线
- Hero 页（01/07/12/17/21）：主色 55–60% / 辅色 20–30% / **强调 15–20%**
- Supporting 页：主色 60% / 辅色 ≤ 20% / **强调 ≤ 5%**
- Transition 页（03/06/11/18）：主色 70%（含蒙版）/ 强调 ≤ 8%

### 2.2 渐变与半透明（唯一许可清单）
- 强调渐变（仅用于封面标题装饰条、Hero 焦点条、图表主系列）：`linear-gradient(135deg, #35D0BA 0%, #4C8DFF 100%)`
- 图片蒙版（章节扉页、封面右半）：`rgba(15,27,45,0.55)` 覆盖在图上，保证白字可读
- 卡片浮起：`boxShadow: '0 4px 20px rgba(0,0,0,0.35)'`
- 叠层装饰（背景网格 / 大号序号水印）：`opacity: 0.06–0.12`
- 禁止：径向渐变、多色撞色铺底、整页纯色无层次。

## 4. 密度门禁

- 内容页正文下限 **180 字**；卡片组每卡 ≥ 100 字。
- 常规页留白 **≤ 35%**；Hero / 章节 / 结束页可到 40–50%，但留白必须围绕锚点元素，禁止均匀稀薄。
- 容器填充率 ≥ 85%：卡片尾部标签条 / 结论条用 `marginTop: 'auto'` 钉底；同行兄弟卡的「标题块 / 正文块 / 尾部条」三段 y 轴对齐，偏差 ≤ 16px。
- 焦点留白：巨型数字、核心图周围 ≥ 40px 呼吸空间。

## 7. 全篇自检红线
1. 相邻页版式不得重复；连续 2 页对称必须打断。
2. 强调色仅出现在焦点元素，Supporting 页 ≤ 5%。
3. 标题块右侧禁止任何装饰小图；L3 角标只在页脚左端。
4. 每页至少 1 个视觉锚点（≥ 96px 数字 或 ≥ 40% B 区面积的图 / 色块）。
5. 高度累加：20 + 120 + 540 + 60 + 20 = 760 > 720 → 实际按「上 padding 20 + A 区 100 + B 区 540 + C 区 40 + 下 padding 20 = 720」执行，B 区内容高度上限 **540px**，超出即返工。
